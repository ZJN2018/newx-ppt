# 故事线确认模板

只填**一条**故事线，发给用户确认或修改，并调出选择框：① 确认这条故事线（推荐）② 我要修改 ③ 你定。不要同时给第二条、第三条备选。

确认到下面四层，从外到内：

1. **部分**：章节（目录上的一章）。
2. **页标题观点** / **主要内容**：这一页的结论句，以及支撑它的数字和要点。
3. **页内中标题或中观点**：各区域各写一句可检验的判断。
4. **中观点论据**：每个中观点下 2 条左右论据要点，带关键数字或事实；多个中观点的论据按顺序写，用“｜”分开对应的中观点。口径、比较基准和出处不必写在这里，留到论据底稿。

用户可以改字、改页、改章节。改过的那一版是唯一底稿。内容页缺了页内中观点或论据，不能确认，也不能进入配色和补充材料。

封面、目录可以没有页内中标题和论据。内容页四层都要有。一页一行，标题是结论句（一行，约 28 字内），不是“收入情况”这类话题词。

## 缩进（四层）

与上面的表是同一条大纲，两种写法选一种发给用户。

```text
- 部分：经营概览
  - 页标题观点：提价带来的毛利增量覆盖了新增配送成本
    - 主要内容：同量售价、单位成本与配送费用的同期差额
    - 页内中标题或中观点：同量售价提高扩大了单位毛利；配送成本增加只抵消部分毛利增量
    - 论据：均价由 12.0 元提至 12.8 元；单位毛利增加 0.6 元
    - 论据：配送费用增加 420 万元；毛利增量 980 万元
```
