# 工作汇报：书面语规则

汇报 PPT 用正式书面语，读起来像一份正式报告的提要，而不是聊天或营销文案。

## 用词

| 不用 | 改用 |
|---|---|
| 涨了 / 跌了 / 大涨 / 暴跌 | 同比增长 / 同比下降 / 比上年末上升 / 降幅扩大 |
| 多吃掉、拖累、多缴 | 占用、影响、所得税同比增加 |
| 守住、稳住、控住、扛住 | 保持、巩固、控制在、维持 |
| 打法、拉通、颗粒度 | 方式、统筹、细化程度 |
| 其实、说白了、挺好、不错 | 删去，直接陈述 |
| “量平质降”“一进一出”等自造俗语、比喻 | 直述：“规模基本持平，质量有所下降” |

## 标题

- 不用设问：“利润为什么下降？”“怎么看净息差” ✗ → “利润下降原因分析”“净息差变动分析” ✓
- 内容页标题是结论句；区域小标题写可检验的判断句，图例、轴名和单位可用名词。

## 数字

- 每个数字带比较基准与单位：“同比增加 105.74 亿元”，不写“+106 亿”作句子主语。
- 百分比变化与百分点变化分清：比率的变化用“个百分点 / pt / bp”。
- 同一数字在全稿保持同一精度与写法（643.31 亿元 就不要在别处写成 643 亿）。
- 涨跌用 ▲▼ 符号或“增长 / 下降”文字表达，不依赖红绿色。
- 单独出现的数字必须配标签。

## 页面上不写过程用语

`evidence.md` 里的"论据""核查依据""口径边界"是写底稿和核对用的，**不印到页面上**。格子小标题、要点导语写本页的事项或判断（如"湖滨收入居首""四季度晚到集中"），口径和出处放页脚或格内灰色注释。同一页里每条导语各写各的内容，不重复用同一个标签。

## 判断

- 用审慎措辞：“需关注”“有待加强”“有所放缓”“仍处于较高水平”。
- 不用绝对化表述：“彻底”“全面爆发”“史无前例”。
- 区分事实与判断：材料原文是事实；自己的归纳写进结论带，或在来源注明“属分析判断”。

## 句子

- 短句为主，一条要点一句话说完一个意思。
- 内容页在页标题下写两级：页内中观点，以及它下面的支撑点或细则。确认大纲只写到中观点；成稿必须把支撑点写进对应区域。
- 主语明确，少用“这”“其”指代不清。
- 并列项结构一致（都用动宾，或都用名词短语）。
