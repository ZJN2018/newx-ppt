# 首页、目录、转场的版式

这些版式借鉴了参考稿的构图：照片放在哪里、往哪个方向渐隐、文字放在哪一块。颜色跟随整套主色，照片会先调色再铺满。一套稿子只用一种首页、一种目录、一种转场，前后统一。**版式由脚本按封面标题随机抽取**（同一份稿子重跑结果不变，不同单位的稿子自然不同），生成时会打印抽到的版式。

**模型不要自己写 `settings.styles`。** 之前模型常把每项都写成表里第一种，结果不同公司的稿子首页、目录、转场一模一样。只有用户明确要求某种版式时，才写进 `settings.styles`，并同时写 `"styles_from": "user"`；没有这个标记的 `styles` 在构建时被忽略，照样随机抽。

```json
"settings": {
  "styles_from": "user",
  "styles": {"cover": "fade", "agenda": "photo_left", "transition": "full"},
  "photos": {"cover": "楼宇、总部", "agenda": "办公、会议"}
},
"sections": [{"name": "经营成果", "desc": "…", "photo": "办公、会议"}, …]
```

| 页面 | 写法 | 构图 | 适合 |
|---|---|---|---|
| 首页 / 结束页 | `band` | 整幅照片＋主色蒙版 | 通用 |
| | `fade` | 左字右图，照片向文字区渐隐 | 照片主体在右侧、左侧较空的图 |
| | `center` | 整幅照片，标题居中，上部浅色渐隐 | 天空、远景占上半部的图 |
| | `bottom` | 上图下字 | 横向全景、建筑群 |
| 目录 | `panel` | 左侧主色块＋列表 | 通用 |
| | `photo_left` / `photo_right` | 一侧一栏照片，另一侧编号列表 | 章节 3–6 个 |
| | `columns` | 整幅照片，“目录”居中，编号横排 | 章节 3–5 个、章名短 |
| 转场 | `half` | 左色块＋右半幅照片 | 通用 |
| | `full` | 整幅照片，主色压暗，编号与章名靠左 | 每章都有像样的照片 |
| | `light` | 整幅照片，左侧浅色渐隐，主色大号编号 | 浅色调照片 |
| | `split` | 左侧大号编号与章名，右侧照片 | 照片一般、只想做点缀 |
| | `band` | 照片在上，底部白条写编号与章名 | 横向全景 |

- 有 `settings.logo` 时，首页、目录、转场、结束页右上角都放 LOGO。脚本先估出这块位置叠合后的背景色：浅色放原色 LOGO，深色、主色或照片背景放纯白反白版；色块标（自带底色的方标，含带透明留边的实心色块）原样放。以白色笔画为主的 LOGO，深色背景放原图；浅色背景上原色看不清时换深色剪影。任何情况都不垫白色底卡。
- **全图蒙版版式的背景照片做模糊**：首页 `band` / `center`、目录 `columns`、转场 `full`（以及同款结束页）整幅铺图、上面压蒙版写字，照片先做高斯模糊（`photos.BG_BLUR`，按 1280 宽约 7px），字更清楚、画面更干净。照片只占一侧或向一侧渐隐的版式（`fade`、`bottom`、`photo_left/right`、转场 `light` / `split` / `band` / `half`）不模糊。
- 结束页自动和首页用同一种版式、同一张照片，大字“感谢聆听”，下方列汇报人。
- 目录照片优先用 `settings.photos.agenda`，没有时用首页那张。
- **转场页一律带照片，不用纯色底**（纯浅底、纯主色底都不行）。从上表带照片的版式里选一种（`half` 也带右半幅照片），一套只用这一种。
- 转场照片用 `sections[].photo`。某章没取到时，依次按章名、通用"办公、会议、城市"补图，再不行借用封面图，并打印提醒；不退回纯色底。
- 照片质量决定这几种版式的效果。首页、目录没有照片时，脚本自动退回 `band` / `panel`；转场页见上一条，必须有图。
- 照片调色：首页、结束页基本保留原色；目录、转场、正文配图柔和但不发灰发棕（保留饱和度约 60%，主色调色约 12%；食品类 75% / 8%，参数在 `photos.tone_for`）。
