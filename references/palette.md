# 配色

主色有两种来源：**LOGO 原色**，或**色库**（11 套预设色系＋17 种扩充主色）。浅色底、卡片、文字灰阶、渐变、强调色都由 `derive()` 按主色推导，所以任何主色都能得到一整套配色。SKILL 按下面的规则算出**推荐配色**，再配 2 个备选，**用选择框请用户选**（推荐项放第一个，另留“你定”）；不让用户自己输入色值。规律来自对 42 套参考配色的实测，代码在 `scripts/palette.py`。

## 一、怎么指定

1. **有 LOGO**：取 LOGO 主色（有图形部分取图形颜色，否则取文字颜色），**直接用原色**推导整套配色，`settings.preset` 写色值（如 `"#E30613"`）。浅色 LOGO（黄、浅蓝）会自动压暗到白字可读；过灰、过深（饱和度 < 0.15 或亮度 < 0.08）的 LOGO 退回 `nearest_preset()` 最接近的预设，黑白 LOGO 用"炭灰"。
2. **没有 LOGO**：按行业从色库里列出候选（每个常见行业 3～6 种），按大纲标题稳定地挑一种做推荐、另两种做备选。同一份稿子重跑颜色不变，同行业的不同稿子颜色不同。
3. **都判断不了**：用"藏蓝"。

```python
import palette, deckkit as K
pal = palette.preset("#E30613")                  # LOGO 原色
pal = palette.preset(palette.by_industry("医药", "某某年度总结")[0])   # 按行业
palette.apply(K, pal)
```

## 三、推导规律（`derive()`）

| 用途 | 规则 |
|---|---|
| 主色 | 白字对比度不足 3 时逐步压暗 |
| 色相族 | 冷色 170°–300°，绿色 75°–170°，其余为暖色（300°–330° 的玫紫归暖色，避免整页发粉） |
| 浅色底 | 冷色：主色色相、饱和度 0.38；暖色：40° 米白、饱和度 0.22；绿色：主色色相、饱和度 0.10。页面底亮度 0.955，卡片底亮度 0.935 |
| 卡片描边 | 同色相，亮度 0.885 |
| 正文三档 | 主色色相；亮度 0.14（标题与重点）、0.30（正文）、0.50（注释） |
| 分隔线 | 浅色底同色相，亮度 0.86 |
| 深色块渐变 | 主色 → 同色相、亮度 +0.12 |
| 图表系列 | 主色＋4 档带主色色相的灰（见下节） |
| 强调色 | 冷色配暖橙，暖色/绿色配浅金；橙、黄主色配低饱和灰蓝（不用深墨） |

## 四、重点怎么标（v2.4.0）

**重点 = 主色，非重点 = 灰。不另设一个颜色做"重点"。** 主色本身就是全稿最醒目的颜色，再找一个颜色来抢"重点"只会打架：深墨色像"黑掉"，同色相的橙红分不出层次，补色（如橙配青绿）两个都饱和、明暗又接近，转灰度后分不清。

| 元素 | 有重点时 | 没有重点时 |
|---|---|---|
| 条形图 | 重点条（1～2 根）主色，其余 `norm` 灰，数值标签同色 | 全部主色 |
| 环形图 | 首项主色，其余按 `grays` 由深到浅 | 同左 |
| 时间轴 | 重点节点主色，其余节点 `norm` 灰 | 全部主色 |
| 占比对比条 | 最大一项主色，其余 `norm` 灰 | — |
| 小装饰 | 标题竖条、目录序号、转场短横、小标题竖条、编号圆点、箭头：一律主色 | |

- `norm`、`grays` 由主色推出：主色色相、饱和度约 0.1，明度 0.72（`norm`）及 0.52 / 0.72 / 0.83 / 0.90（`grays`）。暖主色得到暖灰，冷主色得到冷灰，不用另写。
- 不用"浅主色 = 普通、深主色 = 重点"的同色分级：重点出不来。
- **灰度自检**：页面转黑白后，重点仍能一眼看出。
- 主色的大色块（渐变卡片、结论条、表头）照常用，不限面积。上面的规则只管"数据图形里哪个是重点"。

## 五、状态色

进度、风险类状态需要颜色时，在主色之外只加强调色表示"需关注"，并始终配文字标签（如"滞后""风险"），不单靠颜色表达。

**强调色整稿只表达一种意思。** 一套里用强调色标"需关注 / 差距 / 未达标"，就不要在别的页用它标"收入增长""最好的一项"；正向的重点用主色加粗或主色深一档。
