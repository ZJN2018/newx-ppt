# 渲染与预览

1. 运行 `python3 scripts/build.py deck.json --out out/ --evidence evidence.md`。脚本先做规格检查，有错误就停；警告（数字未在底稿出现、相邻页切分雷同等）逐条核对后决定是否修改。通过后生成 PPTX、PDF、逐页 `-p-N.png` 和 `-overview.png`，再按逐页图量每格实际空块：提醒打印在终端并写入 `<名>-留白检查.json`。逐条处理：先收格、换紧凑组件或与相邻页合并；内容确实只有这些时，加一个挨着正文区一角的图片格（见 [组件目录·图片](components.md)）。也可单独运行 `python3 scripts/check_blank.py out/<名>-layout.json`。用了联网图片时，看总览核对内容是否相关、有无地标与人物，只把明显不合适的换一次关键词；并把生成时的版权提醒转告用户。
2. 看总览：章节节奏、区隔方式是否交替、深浅与疏密是否均衡、相邻页是否同构。
3. 打开每张单页，按 [细节清单](details.md) 逐项复核：溢出、截断、换行、对齐、图片色调。记录页码、实际缺陷和改法；改 `deck.json` 后重新生成，最多三轮。对贴边文字预留不同演示字体的余量。
