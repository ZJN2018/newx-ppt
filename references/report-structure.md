# 整稿页序

先用已经确认的章名和页观点安排页序，再逐页决定版面。固定顺序：**封面 → 目录 → [章节转场 → 正文页…]×N → 结束页**，由 `build.py` 按 `deck.json` 自动生成。

| 位置 | 谁提供内容 | deck.json 字段 |
|---|---|---|
| 封面 | 模型从原材料提取标题、期间、单位和日期；副标题写一句总判断。出现指标时沿用正文的完整指标名和口径。 | `settings.title / subtitle / org / date`，配图 `settings.photos.cover` |
| 目录 | 故事线的章名、顺序和一句说明，3–6 章。 | `sections[].name / desc` |
| 开篇总判断 | 经营分析的第 3 页给出关键数和主判断，与正文一样进入论据底稿。 | `pages` 第一项，`section` 用首章名 |
| 章节转场 | 正文页进入新章节时自动插入，显示章号、章名和说明；整稿样式统一。 | `sections[].photo` 可配图 |
| 正文 | 每页一个结论：标题是判断，正文区按切分树放证据。 | `pages[]`，见 [版面切分规格](split.md) |
| 收尾 | 最后一个正文页承载建议、待决策事项或监测指标，随后是结束页。 | 结束页与封面同图同蒙版，大字「感谢聆听」，下方列汇报人：`settings.reporter`（材料没给则列单位） |

完整字段见 [deck.json 格式](deck-json.md)。
