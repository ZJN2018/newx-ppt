# 视觉规范

## 一、整体风格

- **扁平渐变**：色块、表头、深色卡片、条形图用小幅渐变；不用立体效果、重阴影、发光和描边浮雕。
- **卡片**：浅底卡片用近乎看不出的 0.5pt 描边，加柔和阴影（模糊 37pt、偏移 3pt、方向 45°、黑色透明度 93%）。有描边和无描边二选一；选无描边就必须配这种柔阴影。
- **圆角**：整套统一，直角或小圆角（半径约 10px）。
- **字体**：全稿统一用思源黑体（Noto Sans CJK / Source Han Sans）。

## 二、文字层级

| 层级 | 字号（px） | 颜色 |
|---|---|---|
| 页标题 | 32～36，粗体 | 主色 |
| 格内小标题 | 17～19，粗体，左侧主色短竖条 | 主色 |
| 导语 / 关键句 | 18～22，粗体 | 近黑（正文一档） |
| 正文说明 | 15～20 | 深灰（正文二档） |
| 注释、来源 | 11～14 | 浅灰（注释档） |
| 关键数字 | ≥ 28，粗体 | 主色 |

- 色条、深色卡片上的文字一律白色，说明文字用浅色。
- **小装饰一律主色**：封面/结束页标题竖条、目录序号、转场页短横、格内小标题竖条、编号圆点、箭头，都用主色，不用强调色。
- **左边线对齐**：格内小标题的主色短竖条挂在左侧留白里，小标题文字与下面的要点图标、正文、表格、数字共用同一条左边线。
- **格内间距四档**，由小到大、差别不大但要分得出（脚本已按此排版，常量在 `deckkit.py` 顶部）：

| 间距 | 取值 | 说明 |
|---|---|---|
| 行间距 | 导语 1.25 倍，正文 1.42 倍 | 同一段文字内的行距 |
| 段内间距 | 6px | 导语（加粗小标题）到它的说明文字 |
| 段间距 | 18～26px | 一条要点到下一条要点 |
| 标题与正文 | 20px | 格内小标题到下方内容，最大 |
- 数字与单位、百分号不同字号时，底部对齐；单位约为数字字号的 40%。
- 正文不少于半句完整的话，避免只有关键词。

## 三、表格

- 表头整行连续渐变（主色 → 略亮），白字粗体。
- 行高、列宽刚好装下文字，不要拉高拉宽；省下的空间留给其他内容。
- 隔行浅底；需要强调的一行用主色超浅底＋主色粗体。
- 表格不套在卡片里。

## 四、分隔线

- 1px 左右，颜色用分隔线色；两端各缩进 28px。
- 纯线条页全页最多 2 条；线卡混用页的线不碰大卡片。
- 长度不超过两侧内容；线与线、线与组件里的细线不相碰，留缝至少 20px。
- 不用细线隔出放口径、来源的小格子；这些写进页脚。

## 四之二、图表

- 条形图的条不超过约 22px 粗，柱形图的柱不超过约 46px 宽；脚本按格子大小自动调间隙，不要手写过小的 `gap_width`。

## 五、图标

- IconPark 线性图标，线宽统一；颜色跟主色，深色底上用白色。
- 图标和文字意思一致，不用模板残留图标。

## 六、图片

- 正文页内和转场页的图片必须降饱和并向主色调色（场景图保留 25% 饱和度，食品类保留 40%），避免与主色冲突。
- **封面、结束页的照片基本保留原色**（保留约 88% 饱和度，只极轻地向主色靠），饱和度压得太低会发灰、显得别扭。
- 封面蒙版要轻、过渡要宽：照片一侧渐隐到页底色时，渐隐带约占页宽 44%，分多档由实到虚，不出现"断崖"；整幅压色的版式蒙版不超过约 70% 不透明。转场半幅图在接缝处叠渐变。
- **正文配图不加任何文字**（不写"××场景示意"之类的说明），图片只做配图。
- 选图要和本页内容相关；没有合适的图就不放。
- 正文图片至少挨着正文区一角，贴边一侧铺到页面左右边缘；不夹在卡片中间。

## 七、配色

见 [配色](palette.md)。不让用户输入色值：有 LOGO 用 LOGO 原色，没有 LOGO 由 SKILL 按行业从色库指定。
