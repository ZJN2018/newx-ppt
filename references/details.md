# 逐页细节与检查职责

核对渲染图后按下表回到负责规则的模块，调整后复看受影响的整页。

| 检查项 | 阶段 / 负责方 | 怎么处理 |
|---|---|---|
| 页内中观点、数字口径、出处、材料缺口 | 大纲与底稿脚本校验字段，制作者对原文 | 找到原句或算法；缺依据的判断合并、删减或询问补充。 |
| 字号、出框、遮盖、文字相交 | check_spec 按格子尺寸查容量；逐页看真实字体、换行和末行 | 格子坐标全部由切分树算出，不写坐标。字号下限：正文 16px，小标题 20px，关键数字 28px，来源 10.5～11.5px（左对齐一行），页码 12px（居中，在来源下一行）。超容量时拆格、换组件或并页，保全数字和事实。 |
| 格子密度 | check_spec 查格数（2–8）与最小尺寸（240×130）；渲染后 check_blank 量每格实际空块；看图核对空洞 | 文字格看实际行数，表看行列和可读宽度，图看数据、标签和轴；空的格子并入相邻格或换紧凑组件，内容页正文不少于 160 字；仍空时加一个挨着正文区一角、与本页相关的图片格。 |
| 相邻页同构 | check_spec 提示切分签名重复，制作者看总览 | 连续口径对照可以保留，其他情况按真实关系换骨架或图示。 |
| 结论带 | 重复标题按字面规则脚本阻断；同义复述由制作者读内容 | 遮住结论带，若没有损失原因、影响或下一步，即去掉。 |
| 状态与颜色 | 绘制时检查开关冲突；看图核对语义和对比度 | 状态附文字，深色底核对图标；按期、滞后和风险逐条回查原文。 |
| 卡片与并列区 | 估算与自查检查容量；看图核对是否啰嗦、行首/顶部对齐及空洞 | 保留新事实，删复述，缩区或改紧凑行。 |
| 图表和大数字 | 脚本查字号、数字标签；看图核对单位、基准、负值、图例、标签、轴和指标归属 | 用可比单位和有意义的图形；相邻指标不能误配。 |
| 全套 | 看总览与单页 | 页码居中、转场统一、标题一行可读、阅读顺序清楚；清除样例或记录待换占位。 |
| 经营分析专项 | 对经营材料复核 | 开头尽早亮出主判断，结尾给有依据的可跟踪指标。 |

按缺陷定位修订入口：证据或口径回到[故事线与论据](../types/work-report/storyline.md)，用色、卡片、线条和图片色调回到[配色](palette.md)与[视觉规范](visual.md)，目录和转场位置回到[整稿页序](report-structure.md)，切分和区隔方式回到[版面切分规格](split.md)，组件内比例与标签回到[图示与组件](components.md)。
