# 版面切分规格

一页正文 = **页眉（标题）+ 正文区 + 页脚**。正文区按"切分树"切成若干格，每格放一个组件。模型为每页写一份页面 JSON（格式见第六节），由 `scripts/build.py` 画出来；整稿字段见 [deck.json 格式](deck-json.md)。

画布 1280×720 px。正文区固定为 x=48、y=116、宽 1184、高 558。

## 一、四种区隔方式

每页先选区隔方式，再切分。

| 区隔方式 | 格子怎么区分 | 适合 | 约束 |
|---|---|---|---|
| **纯卡片** | 每格是一张卡片，格间留 20px 空隙 | 并列事项、多组论据、文字较多的页 | 卡片高度贴合内容，不出现大片空卡 |
| **纯线条** | 格子没有底色，用细分隔线区分 | 图表、表格为主，需要通透感的页 | 第一刀必须不对称（如 58:42、2:1），大块整块不再切；全页最多 2 条分隔线 |
| **线卡混用** | 一张大卡片承载结论，其余用线条分隔 | 有明确主判断，同时有多组证据 | 必须有 1 张大卡片，面积不小于正文区的 1/3，并且**占可切割区完整的一整条**（第一刀切出的一段，通高靠左/右或通宽靠上/下，同时挨着两个角，不悬在中间、不只挨一个角）；除大卡片外最多再加 1 张小卡片；线不穿过、不沿着卡片边缘描线 |
| **创意型** | 不按切分树，留白构图 | 时间脊柱；原版创意素材（客户名单、SWOT、双向反馈、三级树、中心＋要点、平台＋场景、荣誉等，见 [原版创意素材](creative-assets.md)） | 只用已验证的几种；整稿占比不超过 1/5；不要自创版式 |

通用规则：
- **分隔线两端各缩进 28px**，不顶到区域边缘。
- **分隔线不比两侧内容长**：脚本按两侧格子里组件实际占的范围截线，线只画到较长一侧内容的端点。
- **分隔线之间不相碰**：与另一条分隔线、组件里的细线（如数字之间的竖线）垂直相遇时，各自缩回至少 20px 留缝，不交叉、不顶到。
- **不为口径、来源单独隔一个小格子**：口径、统计范围、未经审计、数据来源这类说明写进本页 `footer`，不放在格子底部用细线隔开（规格检查会拦）。
- **线被截短、旁边空出一大块时**：说明那格内容撑不满，先收格；仍空就在那一角放一个图片格（见 [组件目录·图片](components.md)），生成时脚本会提醒。
- **同一套 PPT 内**，卡片圆角统一（全部直角或全部小圆角）。
- 表格、条形图、环形图这类自带结构的组件，在"纯卡片"页里也不再套卡片底。
- 相邻两页不用同一棵切分树；同一种区隔方式连续不超过 3 页。

**套内版式要有变化。一格不必对应一个中观点**：一格可以只放一组指标、一条关键论据、一个小图示或一句结论，主证据占大格、辅证据拆成几个小格，页面自然切得更细。

**整稿版面变化（规格检查报错）**——结构指纹 = 切法＋格数＋每格组件类型，不看比例，`v[62,38](表格,要点)` 和 `v[55,45](表格,要点)` 算同一种：
- 相邻两页结构指纹不能相同；
- 同一种结构指纹不超过正文页的 20%（至少允许 2 页）；
- 只切一刀分两格的页不超过正文页的 40%，其余要再切（指标带三明治、英雄区＋卫星、主栏里再横切、竖排三四格）；
- 只看切法、不看组件的骨架，同一种不超过正文页的 30%（至少允许 2 页）——换组件不算换版式；
- **田字格**（先切两半、两边再各切两半，`v2(h2,h2)` 与 `h2(v2,v2)` 合并计算）不超过正文页的 20%（至少允许 1 页）；
- **大主块**：至少 1/4 的正文页有一个不再细分、占正文区 40% 以上的格子（图片格不算），主证据整块放大，辅证据拆小格；
- **两分的刀**里，接近对半（较小一段 ≥45%）的不超过一半；按分量切，多用 2:1、3:1、62:38，左右对照这类确需对半的可以保留（等分三四格不计）；
- 正文页 ≥8 页时，至少 1/4 的页切到 4 格以上（竖排四格、2×3、英雄区＋三卫星、主栏＋侧栏三格等）；
- 正文页 ≥8 页时，至少 2 页第一刀就切成 3 段以上（竖排三栏、上中下三段），至少 2 页切到 5 格以上；
- 第一刀至少用 3 种（左右两分、上下两分、竖排三四等分、上中下三段等），只提醒、不规定具体切法；
- 整稿组件种类至少 min(7, 3＋正文页数÷4) 种；
- 同一个格子小标题不在 3 页以上重复（深色结论卡的"判断""结论"除外）。

版面要逐页由模型按材料关系决定，不要写脚本循环套同一个模板。

## 二、切分树

切分只有三种动作，可以嵌套组合：
- **横切（h）**：上下分，`ratio` 是各段高度比。
- **竖切（v）**：左右分，`ratio` 是各段宽度比。
- **等分**：`ratio` 各项相等，如 `[1,1,1]`。

```json
{"cut": "v", "ratio": [63, 37], "children": [
  {"cut": "h", "ratio": [42, 58], "children": [ 格子A, 格子B ]},
  格子C
]}
```

**常用骨架（铺满型）**
| 骨架 | 切法 | 用途 |
|---|---|---|
| 主栏 + 侧栏 | v [63,37] 或 [2,1] | 主证据在左，判断或补充在右 |
| 英雄区 + 卫星 | h [55,45]，下半部 v 等分 | 上方一个主证据，下方 2～3 组辅证 |
| 指标带三明治 | h [30,70] 或 [26,48,26] | 一排关键数字 + 主体 + 结论条 |
| 等分重复格 | v [1,1,1] / [1,1,1,1]，或 2×3 | 并列事项、问题、措施 |
| 左右对照 | v [1,1] | 前后对比、两方案对比 |

## 三、格子尺寸与容量

| 项 | 规则 |
|---|---|
| 最小格子 | 宽 ≥ 240px、高 ≥ 130px（规格检查按此报错）；装表格、图表的格子高 ≥ 220px |
| 一页格数 | 2～8 格；超过 8 格就拆页。格数多时每格仍须满足最小尺寸 |
| 单格容量 | 要点、图标列表每格最多 4 条长要点（单条说明超过一行的算长要点），超过就拆格或拆页 |
| 主体留白 | 正文区空白不超过 40%；内容少时收格、换紧凑组件或并页，不放大字号凑数；仍空时加一个挨着正文区一角的图片格。生成后脚本按渲染图量每格实际空块并提醒 |
| 正文字数 | 内容页正文去空白后不少于 160 字（封面、目录、转场、结束页除外） |

## 四、格子角色

每格标一个角色，帮助选组件、分面积：

| 角色 | 含义 | 面积 |
|---|---|---|
| 主证据 | 支撑本页标题判断的核心材料 | 最大，通常 ≥ 40% |
| 辅证据 | 补充角度、细分、对比 | 中等 |
| 结论 | 一句判断，可配一个小图示 | 线卡混用页里是大卡片 |
| 说明 | 口径、背景、下一步 | 最小 |

`fill: "重点"` 的格子画成深色卡片（主色渐变底、白字），每页最多 1 个。

## 五、整稿结构

固定顺序：**封面 → 目录 → [章节转场 → 正文页…]×N → 结束页**。封面、目录、转场、结束页必须有。转场页可以用照片（见 [素材与版权](assets.md)）。

## 六、页面 JSON 格式

```json
{
  "page_index": 3,
  "section": "收入与成本",
  "title": "同一业务跨区域单价差 1.3–21.3 元，山麓并不低价",
  "footer": "数据来源与口径说明",
  "separation": "线卡混用",
  "partition": {"cut": "v", "ratio": [36, 64], "children": [
    {"role": "结论", "fill": "重点", "title": "判断", "evidence": ["1.1"],
     "element": {"type": "stack", "items": [
        [{"type": "statement", "text": "……"}, 3],
        [{"type": "chain", "rows": [["山麓", "……", "……"]]}, 4]]}},
    {"cut": "h", "ratio": [58, 42], "children": [
      {"role": "主证据", "title": "分业务分区域吨单价（元）", "evidence": ["1.1"],
       "element": {"type": "table", "header": [...], "rows": [...]}},
      {"role": "辅证据", "title": "……", "element": {"type": "points", "items": [...]}}
    ]}
  ]}
}
```

| 字段 | 说明 |
|---|---|
| `title` | 页标题，写成一句判断，一行放得下 |
| `separation` | 纯卡片 / 纯线条 / 线卡混用 / 创意型 |
| `partition` | 切分树；叶子节点就是格子 |
| 格子 `role` / `fill` / `title` | 角色、是否深色重点卡、格内小标题（可省） |
| 格子 `evidence` | 引用论据底稿里的编号，保证每格内容有出处 |
| 格子 `element` | 组件及参数，见 [组件目录](components.md) |
| `creative` | 创意型页面用，替代 `partition`：`kind` 为 `timeline`，或 `asset`（原版创意素材，写 `code`、`texts` 等，见 [原版创意素材](creative-assets.md)）。中心辐射 `radial` 暂停使用 |

所有数字必须来自论据底稿，页面 JSON 里不新增数字。
